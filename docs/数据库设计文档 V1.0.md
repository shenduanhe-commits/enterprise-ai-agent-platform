3. 用户与权限设计

企业系统第一步：

身份管理。

3.1 用户表 user

表：

users

用途：

保存企业员工信息。

字段：

字段	类型	说明
id	bigint	用户ID
username	varchar	用户名
email	varchar	邮箱
password_hash	varchar	密码
department	varchar	部门
status	int	状态
created_at	timestamp	创建时间

示例：

用户：

张三

部门：

销售部

角色：

销售员工

3.2 角色表 role

表：

roles

字段：

字段	说明
id	角色ID
name	角色名称
description	描述

角色：

管理员

部门主管

普通员工

3.3 用户角色关系表

表：

user_roles

关系：

一个用户可以多个角色。

例如：

张三

↓

销售员工

↓

普通用户权限

3.4 权限表 permission

字段：

字段	说明
id	权限ID
code	权限编码
description	描述

示例：

knowledge.read

knowledge.upload

agent.manage

4. AI对话系统设计

这是 AI 产品核心数据。

4.1 会话表 conversation

用途：

保存用户聊天窗口。

表：

conversations

字段：

字段	说明
id	会话ID
user_id	用户
title	标题
status	状态
created_at	创建时间

示例：

用户：

张三


会话：

查询产品资料

4.2 消息表 message

保存每一次：

用户输入

AI回复

表：

messages

字段：

字段	说明
id	消息ID
conversation_id	会话ID
role	角色
content	内容
token_count	token数量
created_at	时间

role：

user

assistant

system

tool


示例：

数据：

{
 "role":"user",
 "content":"查询A100产品信息"
}

AI：

{
 "role":"assistant",
 "content":"A100交付周期为4周"
}
5. Agent执行记录设计（重点）

这是企业 Agent 必须有的。

为什么？

因为企业需要：

AI决策过程可追踪。

5.1 Agent任务表

表：

agent_tasks

字段：

字段	说明
id	任务ID
conversation_id	会话
task_type	任务类型
status	状态
started_at	开始时间
finished_at	结束时间

状态：

pending

running

success

failed

5.2 Agent执行日志表

表：

agent_traces

字段：

字段	说明
id	ID
task_id	任务
agent_name	Agent名称
action	动作
input	输入
output	输出
duration	耗时

示例：

一次请求：

用户：

帮我生成销售报告

记录：

Supervisor Agent

↓

调用 Report Agent

↓

调用 Database Tool

↓

生成报告

6. Tool调用记录设计

企业必须知道：

AI调用了哪些系统。

表：

tool_calls

字段：

字段	说明
id	ID
task_id	任务
tool_name	工具名称
parameters	参数
result	结果
created_at	时间

示例：

Tool:

query_order


参数:

order_id=10001


结果:

已发货
